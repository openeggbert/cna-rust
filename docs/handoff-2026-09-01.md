## 5. Deliberate non-bindings — the reasoning, not the list

The full list is `tools/c-api-inventory/classification.json`; every rule states
its reason, names the Rust code its claim rests on, and the census fails if that
code is absent. Four patterns cover almost all 801:

1. **The Rust projection already is the thing.** A `TouchCollection` is a list
   of small values and `crates/cna/src/input/touch.rs` is that list. Routing a
   query back through C would cost a call to learn what the bits in hand say.
2. **The value is a Rust value.** `.NET` identity and construction boilerplate,
   `Viewport` maths, gamepad and keyboard snapshot queries.
3. **The C shape cannot be projected safely.** The reflective type-reader
   builder writes N bytes at a caller-supplied offset with nothing checking
   either half; a wrapper cannot check them either.
4. **Binding it would make the answer worse.** `RUST-UPSTREAM-027`: CNA's
   sample-duration and sample-size helpers disagree with XNA where the Rust ones
   agree. Calling them would replace a correct answer with a wrong one.

## 6. Blockers

Fifteen `BLOCKED_UPSTREAM` routes, all from `RUST-UPSTREAM-020` (the camera
family). Nothing is blocked on a renderer, a platform, hardware or an asset.

Three deferred families, each tracked with a durable task and a row in
`docs/backlog.md`:

- **`RUST-EXT-016`** — `SpriteFont` and `SoundEffect` cannot adopt a handle CNA
  made, so two content loads stay unbound.
- **`RUST-EXT-017`** — the XACT `disposing` event does not fire when an engine
  disposes its children. Binding CNA's event alone would paper over that.
- **`RUST-EXT-018`** — `DynamicVertexBuffer::AddContentLostHandler` registers a
  handler that is **never emitted**. CNA's event is now bound as the route that
  works; bridging the XNA-shaped one onto it is the remaining work.

### In CNA (five, each with a reproducer that runs without this repository)

| ID | What | Severity |
|---|---|---|

| `RUST-UPSTREAM-024` | The morph-target stride list restates `{32, 52, 56}` where CNA's own table lists eleven; PBR morph targets are unreachable | Capability gap |

CNA rather than Rust, whether it blocks, and the date last measured.

## 12. The number that changed meaning

`boundWithoutSafeCallSite` counted routes whose native table field name appears
nowhere outside `crates/cna/src/native/`. But most of the safe layer does not
touch a field directly — it calls a wrapper in `native/`, and the wrapper calls
the field. So every route behind a wrapper was counted as unreachable.

It read 894 at the start and 1,077 after this session's routes landed. Both were
wrong. The detector is two-hop now, and the honest reading is **303**. That is
the first time this number has meant what it says, and `RUST-CENSUS-002` is now
worth working: 303 routes either need a safe caller or a stated reason.
